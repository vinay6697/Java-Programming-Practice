Cyclic Sort

Given an array of n integers containing numbers from 1 to n in any random order, sort the array in ascending order using the Cyclic Sort algorithm.

Explanation:
In Cyclic Sort, every element is placed at its correct index.
- Element 1 should be at index 0.
- Element 2 should be at index 1.
- Element 3 should be at index 2.
- Element n should be at index n-1.

Continue swapping elements until every element reaches its correct position.

Constraints:
1. Array elements must be in the range 1 to n.
2. All elements must be unique.
3. The array can be in any random order.
4. Do not use any additional array.
5. Sort the array in-place.
6. Time Complexity: O(n).
7. Auxiliary Space Complexity: O(1).

Test Cases:

Test Case 1:
Input: [3, 1, 5, 4, 2]
Output: [1, 2, 3, 4, 5]

Test Case 2:
Input: [5, 4, 3, 2, 1]
Output: [1, 2, 3, 4, 5]

Test Case 3:
Input: [1, 2, 3, 4, 5]
Output: [1, 2, 3, 4, 5]

Test Case 4:
Input: [2, 1]
Output: [1, 2]

Test Case 5:
Input: [4, 2, 1, 3, 6, 5]
Output: [1, 2, 3, 4, 5, 6]
