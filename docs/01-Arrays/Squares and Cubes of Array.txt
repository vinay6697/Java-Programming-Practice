Find the Squares and Cubes of Array Elements

Question:
Write a Java program to find the square and cube of each element in a given array.

Explanation:
Calculate the square by multiplying each element by itself and the cube by multiplying it three times.

Example Input:
[2, 3, 4, 5]

Expected Output:
Number    Square    Cube
2         	     4           8
3         	     9           27
4         	    16         64
5         	    25        125

Test Cases:

1. Input: [2, 3]
   Expected Output: 
	Squares: [4, 9], 
	Cubes: [8, 27]

2. Input: [0, 1]
   Expected Output: 
	Squares: [0, 1], 
	Cubes: [0, 1]

3. Input: [-2, 3]
   Expected Output: 
	Squares: [4, 9], 
	Cubes: [-8, 27]

4. Input: [5]
   Expected Output: 
	Squares: [25], 
	Cubes: [125]

5. Input: []
   Expected Output: No results
