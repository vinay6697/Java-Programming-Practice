Write a Java program to rotate the given integer array to the right by one position.

Explanation:
You are given an integer array. Your task is to rotate the array to the right by one position.

During right rotation:
1. The last element of the array should be moved to the first position.
2. All remaining elements should be shifted one position towards the right.
3. The relative order of the remaining elements must be maintained.
4. The original array should be modified.

Constraints:
1. 1 <= array.length <= 10^5
2. -10^9 <= array[i] <= 10^9
3. The rotation must be performed by exactly one position.

Test Cases:

Test Case 1:
Input:
ar = [1, 2, 3, 4, 5]

Output:
[5, 1, 2, 3, 4]


Test Case 2:
Input:
ar = [10, 20, 30, 40]

Output:
[40, 10, 20, 30]


Test Case 3:
Input:
ar = [5, 10]

Output:
[10, 5]


Test Case 4:
Input:
ar = [7]

Output:
[7]


Test Case 5:
Input:
ar = [-1, 0, 5, -10, 20]

Output:
[20, -1, 0, 5, -10]
