Write a Java program to left rotate an array by K positions.

Left rotation means moving the elements of an array towards the left by K positions. 
The elements removed from the beginning of the array should be placed at the end while maintaining their original order.

Example 1

Input:
Array = [1, 2, 3, 4, 5, 6, 7]
K = 2

Output:
[3, 4, 5, 6, 7, 1, 2]

Explanation:

1. Rotate left by 1 position:
   [2, 3, 4, 5, 6, 7, 1]

2. Rotate left by 2 positions:
   [3, 4, 5, 6, 7, 1, 2]

Therefore, the final rotated array is:
[3, 4, 5, 6, 7, 1, 2]

Example 2

Input:
Array = [10, 20, 30, 40, 50]
K = 3

Output:
[40, 50, 10, 20, 30]

Explanation:

After rotating the array to the left by 3 positions, the first three elements move to the end while maintaining their original order.
