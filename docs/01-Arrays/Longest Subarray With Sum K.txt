Find the Length of the Longest Subarray with a Given Sum

Explanation

Write a Java program to find the length of the longest contiguous subarray whose sum is equal to a given target sum.

A subarray is a continuous sequence of elements taken from an array.

If multiple subarrays have the same target sum, return the length of the longest subarray.

If no subarray with the given sum exists, return 0.

Constraints

1. The array can contain positive, negative, or zero elements.
2. The array must contain at least one element.
3. The target sum can be positive, negative, or zero.
4. The subarray must contain continuous elements from the original array.
5. The length of the subarray cannot exceed the size of the original array.

Test Cases:

Test Case 1:
Input:
Array = [10, 5, 2, 7, 9, 1]
Sum = 15

Output:
2

Test Case 2:
Input:
Array = [1, 2, 3, 4, 5]
Sum = 9

Output:
3

Test Case 3:
Input:
Array = [1, 1, 1, 1, 1]
Sum = 3

Output:
3

Test Case 4:
Input:
Array = [2, 4, 6, 8]
Sum = 15

Output:
0

Test Case 5:
Input:
Array = [3, -1, -1, 2, 5]
Sum = 1

Output:
3
