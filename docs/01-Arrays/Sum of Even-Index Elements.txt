Find the Sum of Even-Index Elements in an Array

Question:
Write a Java program to find the sum of elements present at even indexes in a given array.

Explanation:
Add the elements located at indexes 0, 2, 4, 6, and so on.

Example Input:
[10, 20, 30, 40, 50]

Expected Output:
Sum of even-index elements: 90

Test Cases:

1. Input: [1, 2, 3, 4, 5]
   Expected Output: 9

2. Input: [10, 20, 30, 40]
   Expected Output: 40

3. Input: [5]
   Expected Output: 5

4. Input: []
   Expected Output: 0
