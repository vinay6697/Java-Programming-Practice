 Sum of Odd-Index Elements in an Array

Question:
Write a Java program to find the sum of elements present at odd indexes in a given array.

Explanation:
Add the elements located at indexes 1, 3, 5, 7, and so on.

Example Input:
[10, 20, 30, 40, 50]

Expected Output:
Sum of odd-index elements: 60

Test Cases:

1. Input: [1, 2, 3, 4, 5]
   Expected Output: 6

2. Input: [10, 20, 30, 40]
   Expected Output: 60

3. Input: [5]
   Expected Output: 0

4. Input: []
   Expected Output: 0
