 Find the Sum of Digits of Each Element in an Array

Question:
Write a Java program to find the sum of digits of each element in a given array.

Explanation:
Extract each digit of every array element using the modulo (%) operator and remove the last digit using the division (/) operator. Add all the extracted digits to calculate the sum of digits of each element. For negative numbers, calculate the sum using the absolute value of the number.

Example Input:
[123, 456, 789, 10]

Expected Output:
Sum of 123 is: 6
Sum of 456 is: 15
Sum of 789 is: 24
Sum of 10 is: 1

Test Cases:

1. Input: [123, 456]
   Expected Output: 
	Sum of 123 is: 6, 
	Sum of 456 is: 15

2. Input: [0, 10, 100]
   Expected Output: 
	Sum of 0 is: 0, 
	Sum of 10 is: 1, 
	Sum of 100 is: 1

3. Input: [999, 1234]
   Expected Output: 
	Sum of 999 is: 27, 
	Sum of 1234 is: 10

4. Input: [-123, -456]
   Expected Output: 
	Sum of -123 is: 6, 
	Sum of -456 is: 15

5. Input: [7]
   Expected Output: 
	Sum of 7 is: 7

6. Input: []
   Expected Output: No results
