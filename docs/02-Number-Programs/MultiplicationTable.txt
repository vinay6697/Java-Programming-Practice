Print Multiplication Tables from 1 to a Given Number


EXPLANATION:

Write a Java program to print the multiplication tables of all numbers starting from 1 up to a given number.

The program should accept an integer as input and display the multiplication tables of every number from 1 to the given number.

Each multiplication table must contain multiplication results from 1 to 10.

For example:

If the input number is 2, the program should display the multiplication tables of 1 and 2 side by side.

The output should display the corresponding multiplication results in each row, with the multipliers ranging from 1 to 10.


CONSTRAINTS:

1. The input must be a positive integer.
2. The multiplication tables must start from 1.
3. The multiplication tables must end at the given input number.
4. Each multiplication table must contain 10 multiplication results.
5. The multiplier must start from 1 and end at 10.
6. Each table must be displayed in a separate column.
7. The multiplication results must be displayed row by row.
