Check Whether a Given Number is a Prime Number


EXPLANATION:

Write a Java program to check whether a given number is a Prime Number or not.

A Prime Number is a natural number greater than 1 that has exactly two distinct factors: 1 and the number itself.

The program should accept an integer as input and check whether the given number is divisible by any number other than 1 and itself.

If the number has exactly two factors, it is considered a Prime Number. Otherwise, it is not a Prime Number.

For example:

If the input number is 7,

The factors of 7 are 1 and 7.

Since 7 has exactly two factors, it is a Prime Number.


CONSTRAINTS:

1. The input must be an integer.
2. A prime number must be greater than 1.
3. The number 1 is not considered a Prime Number.
4. The number must be checked for divisibility by integers starting from 2.
5. A number is considered prime only if it has exactly two factors.
6. If the number is divisible by any integer other than 1 and itself, it is not a Prime Number.
7. Negative numbers, 0 and 1 are not Prime Numbers.
