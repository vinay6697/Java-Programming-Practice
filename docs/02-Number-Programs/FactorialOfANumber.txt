Calculate the Factorial of a Given Number

EXPLANATION:
Write a Java program to calculate the factorial of a given non-negative integer.

The factorial of a number is the product of all positive integers from 1 up to that number.

It is represented by the symbol (!).

For example:
The factorial of 5 is:

5! = 5 × 4 × 3 × 2 × 1 = 120

The program should accept an integer as input, calculate its factorial, and display the result.

CONSTRAINTS:
1. The input must be a non-negative integer.
2. The factorial of 0 is always 1.
3. The factorial of 1 is always 1.
4. Negative numbers are not considered valid inputs.
5. The output must represent the exact factorial value without overflow.

TEST CASES:

Test Case 1:
Input: 5
Output: 120

Test Case 2:
Input: 4
Output: 24

Test Case 3:
Input: 6
Output: 720

Test Case 4:
Input: 1
Output: 1

Test Case 5:
Input: 0
Output: 1
