Table  Format

Write a Java program to print the multiplication table for a given number from 1 to 10.

Explanation:
1. Read an integer from the user.
2. Use a loop to iterate from 1 to 10.
3. Multiply the given number by the current loop value.
4. Print the multiplication expression along with its result.

Constraints:
1. The input must be a positive integer.
2. The multiplication table must be printed from 1 to 10.
3. Use a loop to generate the multiplication table.
4. Display the output in the format: number * multiplier = result.
